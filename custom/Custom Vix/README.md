# Custom Vix

Custom VIX pane. TradingView can plot VIX as its own symbol; this script is a compact overlay-style watch for elevated volatility on the chart you are already using.

## What was customised

- Daily VIX close is requested onto the current chart in a separate pane.
- A configurable threshold line, with the pane shaded when VIX is above that level.
- Symbol defaults to `CBOE:VIX` and can be changed.
- Shade opacity is an input.
