# VixFix with VIX

Personal customisation of [Larry Williams VixFix](../../Larry%20Williams%20VixFix) that overlays CBOE VIX on the same pane.

The canonical VixFix script (lookback lengths, buy/sell plots, and statistics, without VIX) remains in [`Larry Williams VixFix`](../../Larry%20Williams%20VixFix).

## What this adds

- Optional CBOE VIX series, offset for display alongside VixFix
- Configurable VIX threshold with pane highlighting
- Toggles to enable or disable buy signals, sell signals, and the VIX overlay independently

## 🚀 Installation

1. Open TradingView and navigate to the Pine Editor
2. Copy the contents of `larry-williams-vixfix-with-vix-indicator-script`
3. Paste into the Pine Editor
4. Click "Add to Chart"
5. Configure your preferred settings in the indicator inputs
