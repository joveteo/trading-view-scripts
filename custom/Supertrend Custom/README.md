# Supertrend Custom

Personal SuperTrend customisation with an SMA overlay and a table showing the percentage of bars spent in green versus red.

## ✨ Features

- SuperTrend line with ATR period and multiplier inputs
- SMA overlay (default length 200)
- Buy/sell labels on SuperTrend flips
- Green/red time-percentage table and current streak
- Optional bar colouring by SuperTrend direction

## 🚀 Installation

1. Open TradingView and navigate to the Pine Editor
2. Copy the contents of `supertrend_custom_script`
3. Paste into the Pine Editor
4. Click "Add to Chart"
5. Configure your preferred settings in the indicator inputs
