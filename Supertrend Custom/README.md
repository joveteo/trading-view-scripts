# Supertrend Custom

SuperTrend line with an SMA overlay (length 200 by default) and a table of the share of loaded bars spent in green versus red, plus the current streak. ATR period, multiplier, source, and table position are inputs. Buy and sell labels fire when the SuperTrend direction flips.
